# VoteUp - Online Voting System
VoteUp is a secure full-stack online voting platform that enables administrators to create elections, candidates to participate, and voters to cast their votes digitally. The platform provides authentication, payment verification, vote security, and real-time election management.

## Features

### Admin
- Dashboard
- Create and manage elections
- Create and Approve candidates
- View election statistics
- Manage users

### Candidate
- Edit profile
- View election status

### Voter
- Register/Login
- Verify account
- View elections
- Cast vote securely
- View profile and voted history

### Authentication
- JWT Authentication
- Forgot Password
- Reset Password
- Protected Routes

### General
- Responsive UI
- Toast Notifications
- Secure API
